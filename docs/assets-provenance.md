# Asset provenance

What is in `public/` and where it came from, as far as this repository records. Anything marked **to confirm** is something only the project's author can answer; it is listed so it is checked before the submission, not because it is known to be a problem.

## Authored in this repository

| What | Where | Notes |
|---|---|---|
| Characters (mouse, rabbit, bear, crocodile), their faces and animation | `src/scene/chef-model.ts`, `src/scene/diner-model.ts` | Procedural, code only |
| Furniture, appliances (prep counter, grill, stock pot, wok range, brick oven, bench), the terrace and the sign | `src/management/FurnitureView.tsx`, `Primitives.tsx` | Boxes, cylinders and spheres |
| City, weather, lighting | `src/management/City*.tsx`, `CityWeather.tsx` | Procedural |
| Pixel palettes and lookup tables | `public/pixel/*`, `tools/pixel/*` | Generated by the scripts in `tools/pixel/` from captures of this game's own scene |
| Sample kitchens, headlines, dishes, thoughts, awards | `src/` | Written for this game |

All of these files were once loaded from remote URLs and were copied into `public/` so the game makes no outside requests on Reddit. If any of them cannot be shown to be ours to use, replace it before the final upload; the dishes and the soundtrack are the only places the player would notice.

## Third-party packages that ship with the game

- Fonts: Fredoka, Nunito and Pixelify Sans through `@fontsource` (SIL Open Font License 1.1).
- Icons: Lucide (ISC).
- Libraries: React, React Three Fiber, three.js, Radix UI, Tailwind CSS, Hono, zod, Vitest and the Devvit packages, each under its own license in `node_modules`.

## Not used

No payments, no outside HTTP, no blob storage, no remote fonts or images, no user-supplied images.
